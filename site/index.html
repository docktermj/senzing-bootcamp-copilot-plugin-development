Before you start

What you need

  • GitHub Copilot access and a GitHub account signed in to your client. You need read access to this repository to install its plugin.
  • Permission to use plugins. Organization or enterprise policies can restrict marketplace access or plugin installation.
  • Network access to the Senzing MCP server at https://mcp.senzing.com/mcp. The bootcamp needs it to ground Senzing-specific guidance. On a corporate network or VPN, ask for mcp.senzing.com to be allowed.
  • Python 3 available as python3 on your PATH, including on Windows. A python or py alias alone is not enough. The plugin's lifecycle hooks and the graduation recap use Python.
  • Review before trusting: inspect the plugin's skills, scripts, hooks, MCP server, and requested tool permissions. Hooks execute local Python commands.
  • A new, empty project folder for the bootcamp. Keep bootcamp files in that project. You choose it when you start a session.
  • Recommended A business problem and 5,000 to 20,000 records that illustrate it. Helpful, not required to get started.

Install and start

Choose how you use Copilot

Graphical setup

GitHub Copilot app

Install from the app's Customize view. These steps may change with the version of the GitHub Copilot app; see the app's plugin documentation.

  1. Get and install GitHub Copilot.
  2. Open the GitHub Copilot app and sign in with your GitHub account.
  3. Add the marketplace:
    1. In the left-hand navigation, select Customize.
    2. In the upper right, click + Add > Manage marketplaces...
    3. For Source, enter https://github.com/Senzing/senzing-bootcamp-copilot-plugin.
    4. Click Add, then close the Manage marketplaces dialog.
  4. Install the plugin:
    1. In the left-hand navigation, select Customize.
    2. On the top, select the Browse tab.
    3. In the search bar, choose All types.
    4. Search for bootcamp.
    5. Select senzing-bootcamp (version 0.6.1) and click Install.
  5. Start a session in your empty folder:
    1. In the left-hand navigation, select Sessions, then click New (the plus sign +) > Add local folder or repository.
    2. Create or select a new, empty folder.
  6. At the bottom of the Agentic Chat:
    1. In Mode, choose Interactive.
    2. In Model and reasoning:
      1. Enable Copilot Fusion.
      2. Choose the effort level Standard.

Terminal setup

Copilot CLI

These steps use the Copilot CLI plugin commands.

  1. Install GitHub Copilot CLI. It needs an active GitHub Copilot subscription. Use one of these:

    macOS or Linux, install script

    curl -fsSL https://gh.io/copilot-install | bash

    macOS or Linux, Homebrew

    brew install --cask copilot-cli

    Windows, WinGet

    winget install GitHub.Copilot

    Any platform, npm (Node.js 22 or later)

    npm install -g @github/copilot
  2. Add the Senzing Bootcamp marketplace:

    Terminal

    copilot plugin marketplace add Senzing/senzing-bootcamp-copilot-plugin
  3. Install the plugin (version 0.6.1):

    Terminal

    copilot plugin install senzing-bootcamp@senzing-bootcamp
    If the plugin is already installed, update it instead:

    Terminal

    copilot plugin update senzing-bootcamp@senzing-bootcamp
  4. Check that it is installed and enabled:

    Terminal

    copilot plugin list
    The result looks something like this:

    Output

    Built-in plugins:
  • browser-use (v0.1.0) [disabled]

Installed plugins:
  • senzing-bootcamp@senzing-bootcamp (v0.6.1)
    The marketplace name is senzing-bootcamp; the installed identifier is senzing-bootcamp@senzing-bootcamp. Optional direct-subdirectory installation is a separate route, not a marketplace verification.
  5. Create an empty folder for the bootcamp and start Copilot CLI in it. Always use a new session after installing or enabling the plugin:

    Terminal

    mkdir senzing-bootcamp
cd senzing-bootcamp
copilot
    If you are asked to sign in, enter /login and follow the on-screen instructions.

Good to know

Manage the plugin

Copilot app

Open Customize → Installed to turn the plugin on or off. App marketplace and plugin controls can vary; follow the controls shown in your client.

Copilot CLI

To refresh the marketplace catalog and update its plugin, run:

Terminal

copilot plugin marketplace update senzing-bootcamp
copilot plugin update senzing-bootcamp@senzing-bootcamp

To disable or remove it:

Terminal

copilot plugin disable senzing-bootcamp@senzing-bootcamp
copilot plugin enable senzing-bootcamp@senzing-bootcamp
# Only when you want to remove the plugin and catalog:
copilot plugin uninstall senzing-bootcamp@senzing-bootcamp
copilot plugin marketplace remove senzing-bootcamp
